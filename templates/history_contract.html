What this proves

  • The local record hash is the Keccak-256 of the same canonical JSON payload that was submitted on-chain.
  • The on-chain record hash matches that local payload when the event has not been altered.
  • The local block index and local block hash show exactly which local block carried the matching contract_tx_hash.
  • The richer local verification record stores probe hash, embedding hash, discovered posts, and verification metadata for demo/readability purposes only.
  • If the local ledger is tampered with, the recomputed local record hash will no longer match the on-chain record hash.
